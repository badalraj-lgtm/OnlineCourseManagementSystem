Project Description

The Online Course Management System is a console-based Java application developed using Core Java and Object-Oriented Programming (OOP) concepts. The system manages courses, student enrollments, and student progress. It enables students to enroll in courses, update learning progress, and view course details efficiently.

The project demonstrates the practical implementation of Classes, Objects, Arrays, Methods, Constructors, and Encapsulation while simulating a real-world e-learning platform.
